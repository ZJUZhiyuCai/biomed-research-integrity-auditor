# Code of Conduct

## Our Pledge

We want this project to be a respectful, practical, and scientifically careful place for researchers, engineers, reviewers, and maintainers. We welcome contributors regardless of background, career stage, institution, nationality, language, identity, or technical specialty.

This project deals with sensitive research-integrity workflows. Extra care is expected: discussion should stay evidence-based, neutral, and respectful toward authors, journals, reviewers, and contributors.

## Expected Behavior

- Use welcoming and inclusive language.
- Assume good faith while still asking for reproducible evidence.
- Keep criticism specific to code, documentation, data contracts, tests, or audit wording.
- Respect privacy. Do not post private manuscripts, raw biomedical data, patient data, author-identifying material, institution-identifying local paths, or non-public audit outputs.
- Preserve the project boundary: automated candidates are not misconduct findings, and disagreement should not become accusation.
- Accept constructive feedback and help others understand the reasoning behind changes.

## Unacceptable Behavior

- Harassment, intimidation, insults, sexualized language, or discriminatory remarks.
- Publishing private contact information, credentials, manuscripts, raw data, or other confidential material without permission.
- Accusatory claims about misconduct, intent, or guilt in project discussions when the issue is about tool behavior or evidence handling.
- Repeatedly derailing technical discussions, ignoring maintainer guidance, or pressuring contributors to disclose private research material.
- Any conduct that would reasonably make participation unsafe or unprofessional.

## Enforcement

Maintainers may remove comments, close issues, request edits, moderate discussions, or restrict participation when behavior violates this Code of Conduct. Enforcement should be proportionate, transparent when possible, and focused on protecting contributors and research-material privacy.

For ordinary conduct concerns, contact the repository maintainers through GitHub. For security-sensitive issues or reports involving private research material, follow `SECURITY.md` instead of posting details publicly.

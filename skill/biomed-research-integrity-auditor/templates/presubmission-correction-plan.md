## Before Submission / 投稿前核查

Complete each item before submitting. Status values: `open` / `in progress` / `resolved` / `accepted with reason`.

完成以下各项后再提交。状态值：`open`（待处理）/ `in progress`（处理中）/ `resolved`（已解决）/ `accepted with reason`（有说明地接受）。

- Resolve all R4 findings. / 解决所有 R4 发现项。
- Resolve or explicitly document all R3 findings. / 解决或明确说明所有 R3 发现项。
- Add source data and uncropped/raw records for figures that depend on images or quantitative summaries. / 为依赖图像或定量摘要的图片补充源数据和未裁剪/原始记录。
- Update figure legends for cropping, splicing, reuse, normalization, and statistical definitions. / 更新图注，说明裁剪、拼接、重用、归一化及统计定义。
- Update methods for randomization, blinding, sample size, exclusions, reagents, software, and repository accessions. / 更新方法部分，补充随机化、盲法、样本量、排除标准、试剂、软件及数据库登录号。
